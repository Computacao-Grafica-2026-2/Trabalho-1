# Trabalho de Computação Gráfica - WebGPU

Este projeto foi desenvolvido como base para um trabalho acadêmico em Computação Gráfica, com foco em renderização acelerada pela GPU usando WebGPU. A estrutura e os conceitos foram inspirados nos exemplos do repositório de referência do professor Marcos Lage: https://github.com/mlage/curso-cg.

## Requisitos

- Navegador com suporte a WebGPU;
- Node.js instalado;
- VS Code recomendado.

## Como executar

1. Abra o terminal na pasta do projeto.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse a aplicação no navegador em:
   ```text
   http://localhost:3000
   ```

Desenvolvido para a disciplina de Computação Gráfica.
