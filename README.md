# Trabalho 1 - Computação Gráfica

Pipa animada em WebGPU para a disciplina de Computação Gráfica da UFF

## Como rodar

Abra a pasta no VS Code e rode o `index.html` com a extensão Live Server. Precisa de um navegador com WebGPU (Chrome ou Edge).

## Arquivos

- `main.js`: WebGPU, animação e matrizes
- `geometry.js`: vértices e cores dos triângulos
- `shaders.js`: shaders WGSL
- `math.js`: funções de matriz
